How Hindsight memory works in this project

Meeting Prep uses Hindsight as a persistent memory layer. Every contact has its own memory bank, and your preferred briefing style lives in a separate bank.

1. Log the meeting
Upload screen recording + optional notes
2. Extract facts
LLM pulls out topics, promises, concerns & tone
3. Retain in Hindsight
Each fact is stored as a dated memory in the contact’s bank
4. Recall + Style
Agent recalls relevant memories + your preferred writing style
5. Personalized briefing
Full context briefing written exactly how you like it

Key memory features

One memory bank per contact
Everything about one person stays completely separate from everyone else.
Retain
Every promise, concern and topic is stored as a small, dated statement instead of one big transcript.
Recall & Reflect
Before a meeting the agent pulls the relevant memories and builds a briefing from them. You can also see exactly which memories were used.
Style memory (this page)
Your feedback about how you like briefings written is stored in a separate bank and applied to every contact from then on.
